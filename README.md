# my-new-project

Dự án thực hành khởi tạo và quản lý mã nguồn với Git và GitHub.

## Giới thiệu
Dự án được tạo nhằm mục đích thực hành luồng làm việc cơ bản với Git:
- Khởi tạo kho chứa cục bộ (Local Repository).
- Kết nối với kho chứa từ xa (Remote Repository) trên GitHub.
- Quản lý phiên bản tệp tin với `git add`, `git commit` và đẩy mã nguồn lên GitHub bằng `git push`.

## Công nghệ sử dụng
- Git (Version Control System)
- GitHub (Cloud Repository Hosting)
